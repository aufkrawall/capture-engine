# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities by opening a GitHub Security Advisory at:
https://github.com/aufkrawall/captureproject/security/advisories/new

Reports will be acknowledged within 72 hours. We aim to release a fix within 30 days
of confirmation. If a fix cannot be released within 30 days, we will provide a status
update and an estimated timeline.

## Scope

Only the latest tagged release is covered. Pre-release builds and older releases
should be updated to the latest version.

## Out of scope

- CI/CD runner security, deployment infrastructure, or signing infrastructure.
- Third-party dependencies at versions not pinned by the project manifest.
- Theoretical vulnerabilities without a demonstrated exploit path.

## Recognition

Valid reporters will be credited in the release notes of the affected version,
unless they request otherwise.
