### 2026-07-19 - Expose native NVENC split-frame multi-engine encoding

- **Architecture:** `[NVENC] split_encode=auto|disabled|forced|2|3|4` maps directly to FFmpeg's `split_encode_mode` for HEVC and AV1. This uses NVIDIA's supported single-session Split Frame Encoding path: each input frame is partitioned into horizontal strips across available physical NVENC engines, then returned as one ordinary bitstream. It adds no independent encoder sessions, GOP partitioning, packet interleaving, or concatenation layer. `auto` remains the default so the driver can decide from resolution, preset, and tuning; forced counts fall back to the physical encoder count present.
- **Validation and compatibility:** forced H.264 modes fail before codec open because NVIDIA does not support H.264 split encoding. The older custom `split_encode_mode` route remains authoritative with a migration warning. HEVC custom weighted prediction warns that automatic splitting cannot activate and is rejected when combined with a forced split, matching the NVENC SDK incompatibility instead of silently promising unavailable concurrency. The configured value is included in startup diagnostics, option logs expose the effective FFmpeg value, and config reload comparison treats it as an encoder-reinitialization change.
- **Coverage / verification:** focused `VideoEncoderOptionsTest.*:ConfigTest.*` coverage passes all supported spellings, codec boundaries, custom override precedence, invalid values, and weighted-prediction conflicts. Short 4K/60 preset-p7 forced-split HEVC and AV1 FFmpeg smoke encodes opened NVENC and produced output without warnings on the available NVIDIA GPU. Required final clean build `0.1.5105` passed x64/x86 hooks, CaptureEngine/MediaEngine, 149 unit-test objects, all 30 test apps, both Vulkan layers, packaging, import closure, PE mitigations, effective native CFG, architecture, and PDB checks. Its exact-build no-build gate passed the complete native suite and all six Python tool self-tests. Throughput/quality scaling remains a hardware-validation boundary requiring the target multi-engine RTX 4090/5090-class GPU.
