- **Evidence / root cause:** supplied 32-bit BioShock Infinite DX11 session `installed/captureengine/logs/20260715_223043` ran around 54 FPS with the limiter inactive and about five million draws. The same conservative model skipped valid BC5 normal/mask data, array/cube views, clamp-addressed material samplers, and derivative-footprint bias/gradient sampling.
- **Root fix / invariants:** D3D11 shader metadata is now one immutable private COM interface with precomputed sampler/texture lookup masks; SRV structural suitability is cached once on each view; and 2x/4x/8x/16x forced variants plus negative/compliant markers live on the original sampler. - **Coverage / Blackwell policy:** `sample`, `sample_b`, and `sample_d` are derivative-footprint safe; `sample_l`, comparison, and unknown explicit operations are protected. Typed, mipmapped, single-sample Texture2D/array/cube/cube-array views now cover BC1-BC7 (including BC4/5/6), common color/channel float/UNORM/SNORM formats, and legitimate RTV/UAV-capable material resources. Depth, typed integer, typeless/problematic, multisample, non-2D-family, and one-visible-mip views remain blocked. D3D10/11 safe mode requires linear min/mag but permits clamp/mirror-once; all modes reject border, comparison/reduction, and fixed mip ranges. DX12 remains creation-time-only and now rejects border in aggressive mode too. Vulkan remains creation-time/transactional and now rejects border, unnormalized coordinates, compare, special reduction, and nonstandard filters in every mode.
- **Performance / validation:** the intended steady state has no sampler override driver work and no lock/COM/descriptor work on clean draws; a cached version/dirty branch still exists, so “zero overhead” means no measurable submission starvation rather than literally zero CPU instructions. ### 2026-07-15 - Harden module discovery, ring-buffer overflow policies, and byte-safe case folding

- **Broad shipping review / root causes:** fixed-size PSAPI module arrays were iterated using the full required byte count, so a process with more loaded modules than local storage could drive out-of-bounds reads; the 256-entry post-injection verification could also miss a successfully loaded hook. `RingBufferPolicy::Overwrite` advanced only the write index, producing a logical size above capacity and unsigned `Available()` underflow, while zero-capacity and moved-from dynamic buffers could index empty storage.
