# Repo Map

Last cross-checked: 2026-08-03

- top-level repo layout

## Core Tree
- `build.py`
  - Canonical build, lint, format, and test entry point.
- `common/`
  - Shared IPC, config, logging, ABI structs, and RAII helpers.
- `captureengine/`
  - Host and controller-side logic, tray app, injection, config handling, pseudo-overlay, and runtime handoff.
- `hook/`
  - Injected DLL, API hooks, overlay policy, runtime state, and hook-wrapper systems.
- `mediaengine/`
  - Encoding, muxing, audio, video, and media pipeline logic.
- `tests/`
  - Google Test sources and the built `unit_tests.exe` plus copied runtime DLLs.
- `testapp/`
  - Graphics test applications and the integration test runner.

## Important Support and Output Paths
- `external/ffmpeg/`
  - Local FFmpeg install root used by the custom Windows build flow.
- `patches/ffmpeg/`
  - Patch set applied during the custom FFmpeg build.
- `installed/captureengine/`
  - Main runtime output directory for CaptureEngine binaries, logs, and `ffmpeg/` runtime DLLs.
- `installed/testapp/`
  - Built graphics test applications plus local-only vendor runtime DLLs.
- `build/packages/`
  - Automatically replaced `captureengine.7z` and `testapps.7z` artifacts. The latter contains no vendor DLLs.
- `compile_commands.json`
  - Generated by `build.py` for clangd and LSP tooling.
- `llm-wiki/`
  - Derived project knowledge for agents. Useful, but not authoritative over code.

## High-Risk / High-Value Files
- `common/shared_defs.h`
  - Shared-memory ABI. Current shared-memory version is `38` (source-verified).
- `captureengine/injection.cpp`
  - Host-side injection timing and delayed-injection logic.
- `captureengine/inject_main.cpp`
  - Shared-memory setup, config reloads, and inject-overlay runtime handoff flags.
- `hook/main.cpp`
  - Hook bootstrap and wrapper-init decisions.
- `hook/common/dxgi_shared.cpp`
  - Central Present routing and startup bypass behavior.
- `hook/common/dx12_overlay_policy.h`
  - Dense policy helpers for DX12 overlay routing, startup coexistence, and FG transitions.
- `hook/common/overlay_compat.h`
  - Third-party overlay and FFX module detection helpers.

## Practical Notes
- `build.py` compiles test sources even on non-test builds so `compile_commands.json` remains useful.
- `tests/unit_tests.exe` is intended to run directly after a successful build because required runtime DLLs are copied beside it.
- DX12 overlay, injection, and FG behavior spans `captureengine/`, `hook/`, and `tests/`; do not reason about one of those areas in isolation.
