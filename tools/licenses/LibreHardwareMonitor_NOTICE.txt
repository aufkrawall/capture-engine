sensor integration. They are fetched from the official LibreHardwareMonitor
v0.9.6 release during the build, verified against a pinned SHA-256 digest and
byte size, and installed into plugins/LibreHardwareMonitor:

Microsoft dependency assemblies - MIT
-------------------------------------

The three System.* assemblies are Microsoft-published NuGet packages
(System.Memory, System.Numerics.Vectors, System.Runtime.CompilerServices.Unsafe)
distributed under the MIT license.

  Source:  https://github.com/dotnet/runtime
  License: https://github.com/dotnet/runtime/blob/main/LICENSE.TXT

They are the dependency closure LibreHardwareMonitorLib.dll needs; CaptureEngine
does not call into them directly. The build refuses to install any of the three
unless it still carries a valid Authenticode certificate after extraction.

PawnIO kernel driver
--------------------

LibreHardwareMonitor 0.9.6 reads CPU temperature, package power and core clocks
through PawnIO, a separately installed kernel driver. CaptureEngine bundles the
official Microsoft-signed installer (PawnIO_setup.exe) in plugins/LibreHardwareMonitor
for optional offline installation. See PawnIO_NOTICE.txt for full licensing terms
(GPL-2.0 with Device IO Control Interface Exception), source code availability,
and verification details.

Packaging boundary
------------------

CaptureEngine's package staging uses an explicit allowlist for the plugins
directory: the four files above plus that directory's README.txt. Every other
file a user adds locally - the LibreHardwareMonitor GUI executable, PDBs,
storage/SMBus helpers, notices - is excluded from the release archive.

Anyone redistributing a combined installation containing LibreHardwareMonitor or
its dependencies is responsible for satisfying the applicable MPL-2.0 and
dependency-license requirements, including carrying the upstream license and
third-party notices and meeting any corresponding-source obligations.
